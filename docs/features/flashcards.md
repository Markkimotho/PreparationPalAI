# Flashcards

Flashcards are useful for definitions, relationships, assumptions, and small steps
you want to retrieve from memory. They work best when each card asks one clear question.

## Make a deck

Open **Flashcards**. You can create an empty deck and add cards by hand, or generate
a deck on a topic from indexed material. Automatic generation needs relevant notes
in the knowledge base and an available model.

For a manual card, enter a **Front** prompt and a **Back** answer, then choose
**Add card**. Review generated cards before studying them; remove or replace cards
that are vague, duplicated, or inaccurate.

| Hard to recall clearly | A more useful card |
| --- | --- |
| “Explain thermodynamics” | “What does the first law say about a closed system?” |
| “Everything about binary search” | “Which invariant keeps the target inside the search interval?” |
| “Hardy–Weinberg” | “What does 2pq represent?” |

## Study a deck

Select **Study** from the deck. Try to answer before flipping the card, then mark
**Again** or **Got it** honestly.

| Action | Keyboard shortcut |
| --- | --- |
| Flip the card | Space |
| Mark Again | Left arrow |
| Mark Got it / advance | Right arrow or Enter |

When a button has keyboard focus, its usual Enter/Space action takes precedence.
You can also use the visible buttons on a phone or tablet.

## Interpret the score

The score reflects the cards you marked as known during that run. It is a
self-assessment, not an independent test of mastery. Try the deck again later
without first reviewing every answer.

Decks persist across normal restarts. The current study run can be lost when
you leave the page. There are no automatic spaced-repetition reminders; choose
your own review schedule.
Open a deck to [download a study pack](exports.md). Card fronts become questions;
card backs appear only in the separate answer key.

!!! warning "Deleting is permanent in the app"
    Deleting a card or deck has no learner-facing undo. In a shared workspace,
    it can affect other people using that deck.
