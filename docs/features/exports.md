# Take your practice offline

Use **Download** on a Quiz Prep question set, a Preparation Coach session, a
Study Agent quiz, or a flashcard deck. Choose the study pack and file type first.

| Study pack | What you get |
| --- | --- |
| Exam | Questions and options, with blank answer fields |
| Written worksheet | Space to explain your answer and show working |
| Revision checklist | A checkbox for each question and space for revision notes |
| Separate answer key | Reference answers and explanations, when available |

PDF packs have editable form fields. Open the downloaded file in a PDF reader,
enter your answers, and save a copy. You can also print it and write by hand.
Some browser previews handle forms differently; use a dedicated PDF reader if
entries do not save. The answer key is a separate file and is never embedded in
the exam or worksheet.

Choose **Markdown** to edit or reuse the text in another application. Exported
answers are not submitted back to PreparationPalAI and do not change your score.

Coach packs contain the session’s question set. Finish the session before
downloading its answer key. Flashcard fronts become questions and backs become
reference answers. Study Agent downloads appear after a successful quiz.

Packs support up to 50 questions or cards. Split a larger deck before exporting.
If a question is too long to fit legibly in a PDF, choose Markdown or shorten the
question. Scientific symbols are preserved; complex LaTeX remains text in exports.

Read the questions and check their references before using a pack as an assessment.
AI-generated material can still contain mistakes.
