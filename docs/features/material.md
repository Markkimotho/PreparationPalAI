# Your study material

Your knowledge base is the collection of material the app can use to answer
questions and create study aids. A focused set of relevant notes is usually more
useful than a large, unrelated collection.

## Upload notes

1. Open **Knowledge base** in the top bar.
2. Select **Upload PDF or image**.
3. Choose your file and wait for indexing to complete.
4. Check that the source appears in the indexed file list before starting document-based practice.

Supported uploads include **PDF, PNG, JPEG, WebP, TIFF, BMP, and GIF**. Scanned PDFs
and images are read with OCR when available. HEIC and Word files are not supported
uploads; convert them to PDF, PNG, or JPEG first.

By default, an upload accepts up to **three files**, each up to **20 MiB**. A shared
installation may use different limits.

!!! tip "Make scans easier to read"
    Use a straight, sharp image with good contrast. Avoid cropped equations,
    overlapping handwriting, and tiny labels. For a multipage scan, a PDF is a
    better choice than a single image file.

## Add a web topic

In Knowledge base, enter a specific topic in **Scrape a web topic…** and select
**Index**. The app searches for relevant pages and adds readable content.

Web material can vary in accuracy and coverage. Review the listed sources before
relying on them for an assessment. For a course-specific question, your syllabus
or lecture notes are usually the better starting point.

## Check a job or retry

Open **Recent ingestion jobs** to see whether a request is pending, running,
completed, or failed. Uploads are saved as jobs, so refreshing the page does not
discard the work already submitted.

For a failed job, check that the app is online, then choose **Retry ingestion**.
If the same file repeatedly fails, try a smaller file or a cleaner scan. Your role
must allow changes to the knowledge base.

## Understand source references

The app splits readable text into smaller pieces called **chunks**. The chunk
count is not the page count. Uploading identical material can add no new chunks
because it has already been indexed.

Document chat includes source labels and page references. Compare the cited
passage with the answer, especially for numerical results, diagrams, or OCR text.
Some references use a zero-based page index: **page 0** means the first page.

## Clear material carefully

**Clear** removes the workspace’s indexed knowledge base. It is a workspace action,
not just a way to clear the current conversation. In a shared workspace, it affects
other authorised people using that material. There is no learner-facing undo.

[Privacy and workspaces](../help/privacy.md) explains who can access shared material.
