# Questions and limitations

## Can I study any subject?

You can supply a topic or material across sciences, mathematics, engineering,
computing, and other fields. There is no short list of allowed disciplines.

That does not mean every subject has been validated equally. Specialist terminology,
advanced derivations, recent research, and OCR-heavy material need careful checking.
Use trusted sources and verify important answers.

## Do I need to upload documents first?

**Preparation Coach** can start from a topic using labelled general model knowledge.
**Quiz Prep**, **Regular Chat**, and automatic flashcard generation rely on indexed
material. The Programming Assistant can work without documents.

## Will it guarantee an exam or interview result?

No. It can help you practise recall and explanation, identify possible gaps, and
organise revision. Generated questions do not guarantee syllabus coverage, and
model feedback is not an official marking scheme or a hiring decision.

## Can a source-backed answer still be wrong?

Yes. A model can misread a passage, cite the wrong source, use the wrong assumption,
or make a calculation error. OCR can also alter a symbol or a unit. Inspect the
referenced material rather than trusting the existence of a citation.

## Does it grade handwritten work or spoken answers?

You can upload an image for text extraction, but there is no dedicated handwriting
assessment or voice-interview feature. Coach feedback grades the answer you submit
as text or an option. Read extracted equations carefully.

## Does the Programming Assistant run code?

No. It proposes and explains code. Run the code and its tests in your own environment.

## Does it work without the internet?

After the app and models are installed, local study tasks can run without external
AI calls when the model service is available locally. Web search, initial setup,
and downloading additional models need an internet connection.

## Is this website the app?

No. This is the product guide. Use the address provided by your workspace
administrator, or [install PreparationPalAI](../start/access.md) on your computer.

## Are flashcards automatically scheduled?

No. Study mode lets you mark Again or Got it during a run, but it does not currently
schedule spaced-repetition reminders. Choose your own review routine.

## Where should I go to improve the project?

The [contributor handbook](/PreparationPalAI/contribute/) covers development,
architecture, tests, security, and deployment separately from this user guide.
