# Find your way around

## Start with your goal

| Section | Use it when you want to… |
| --- | --- |
| **Preparation Coach** | Follow a structured recap, exam, interview, or weak-area session |
| **Quiz Prep** | Take a configurable quiz from indexed study material |
| **Study Agent** | Ask a tutor to search, explain, quiz, and grade in a conversation |
| **Regular Chat** | Ask questions about documents and see their source references |
| **Flashcards** | Make a deck and practise active recall |
| **Programming Assistant** | Discuss, explain, or debug code |
| **Guide** | Read quick help without leaving the app |

On a phone, open the menu to move between sections. You can close the drawer with
**Close menu** or **Escape** when using a keyboard.

## The model picker

The top bar shows the selected model. Each study section can remember its own
choice. **Model info** explains the model’s recommended use and which capabilities
are known or still unverified.

If a model isn’t installed, an administrator can select **Pull** to download it.
[Choose a model](../features/models.md) explains the available choices.

## Knowledge base

The **Knowledge base** control holds your workspace’s indexed material. You can
upload PDFs or images, look up a web topic, check recent ingestion jobs, and see
which sources are ready to use.

Wait until an upload or search finishes before expecting it to appear in answers.
The source list and chunk count indicate indexed material, not a count of pages.

## What is saved?

- **Coach sessions and results** are saved on the installation and can be resumed.
- **Flashcard decks** and indexed material persist across normal restarts.
- **Chat conversations** have more limited lifetimes. Moving between sections,
  refreshing, or restarting the service can end the current chat context.
- Your browser remembers a **learner profile** for coach history. Clearing browser
  storage can make the app treat you as a new learner.

In a shared workspace, authorised people may share material. Read
[privacy and workspaces](../help/privacy.md) before uploading personal notes.

!!! tip "Pick the right place for the task"
    Use the coach for a saved assessment session. Use chat for exploring a question.
    A chat transcript is not the same as a saved coach session.
